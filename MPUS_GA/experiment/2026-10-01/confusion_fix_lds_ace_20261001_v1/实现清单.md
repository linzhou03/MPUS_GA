# 混淆矩阵改进实验完整实现清单

## ✅ 已完成的文件

### 1. 核心改进模块

#### `trial_temporal/losses/asymmetric_confusion.py`
- **功能**：非对称混淆损失，重点惩罚 positive 误判
- **关键参数**：
  - `margin_strength=0.3`：margin loss 权重
  - `disagreement_threshold=0.15`：三尺度分歧阈值
- **测试**：`python -m trial_temporal.losses.asymmetric_confusion`

#### `trial_temporal/calibration/multiscale_balance.py`
- **功能**：多尺度类别平衡校准
- **关键机制**：
  - 0-300 步：更新源域混淆矩阵
  - 300 步：冻结混淆矩阵，启动校准
  - 300 步后：估计目标 prior，校准 logits
- **测试**：`python -m trial_temporal.calibration.multiscale_balance`

#### `trial_temporal/pseudo_label/confusion_aware_cbst.py`
- **功能**：Confusion-Aware CBST 伪标签选择
- **关键策略**：
  - Positive 候选：要求低分歧（三尺度一致性）
  - Non-positive 候选：排除有尺度给 positive 高概率的样本
- **测试**：`python -m trial_temporal.pseudo_label.confusion_aware_cbst`

### 2. 训练入口

#### `trial_temporal/train_confusion_fix.py`
- **功能**：集成三个模块的训练入口
- **支持配置**：baseline, asy, cal, cbst, asy_cal, asy_cbst, cal_cbst, full
- **命令示例**：
```bash
python -m trial_temporal.train_confusion_fix \
  --experiment A --config full \
  --random-seed 43 --target-subjects all \
  --data-root /path/to/data \

```

### 3. 调度系统

- **特点**：
  - 统一任务队列
  - 文件锁保证线程安全

  - 支持中断恢复

#### `scripts/run_confusion_fix_suite.sh`

  - `bash scripts/run_confusion_fix_suite.sh start`

### **关键任务**：修改 `trial_temporal/train_cbst.py` 以集成改进模块

由于 `train_cbst.py` 是现有的完整训练流程，我们的三个模块需要在以下位置插入：

#### **插入点 1：初始化阶段**（约第 50-80 行）
在 `settings()` 函数返回后，添加模块初始化：

```python
def main():
    # ... 现有代码 ...
    args, spec = settings(...)
    
    # 【新增】加载 confusion_fix 模块
    if hasattr(args, '_confusion_fix_modules'):
        confusion_fix = args._confusion_fix_modules
        print(f"启用混淆改进模块: {args._confusion_fix_config}")
    else:
        confusion_fix = {'asy_loss': None, 'calibrator': None, 'ca_cbst': None}
```

#### **插入点 2：训练循环中的源域阶段**（约第 150-200 行）
在源域前向传播后，更新校准器的源域混淆矩阵：

```python
def train_step(model, source_batch, target_batch, iteration, ...):
    # ... 源域前向传播 ...
    source_output = model(source_batch['x'])
    
    # 【新增】更新源域混淆矩阵（0-300步）
    if confusion_fix['calibrator'] is not None and iteration < 300:
        scale_logits_list = [
            source_output['scale_1s_logits'],
            source_output['scale_2s_logits'],
            source_output['scale_4s_logits'],
        ]
        confusion_fix['calibrator'].update_source_confusion(
            scale_logits_list, source_batch['y']
        )
```

#### **插入点 3：第 300 步标记 warmup 完成**
```python
if iteration == 300 and confusion_fix['calibrator'] is not None:
    confusion_fix['calibrator'].finish_warmup()
    print("校准器 warmup 完成")
```

#### **插入点 4：目标域前向传播后应用校准**（约第 250-300 行）
```python
def train_step(...):
    # ... 目标域前向传播 ...
    target_output = model(target_batch['x'])
    
    # 【新增】应用校准（300步后）
    if confusion_fix['calibrator'] is not None and iteration >= 300:
        scale_logits_list = [
            target_output['scale_1s_logits'],
            target_output['scale_2s_logits'],
            target_output['scale_4s_logits'],
        ]
        calibrated_logits_list, cal_diag = confusion_fix['calibrator'](
            scale_logits_list, iteration=iteration, is_source=False
        )
        # 用校准后的 logits 替换原始 logits
        target_output['scale_1s_logits'] = calibrated_logits_list[0]
        target_output['scale_2s_logits'] = calibrated_logits_list[1]
        target_output['scale_4s_logits'] = calibrated_logits_list[2]
```

#### **插入点 5：伪标签选择时使用 CA-CBST**（约第 350-400 行）
找到 CBST 选择伪标签的位置，替换为：

```python
# 原始代码：
# selected_indices, selected_labels = cbst_select(...)

# 【修改为】
if confusion_fix['ca_cbst'] is not None:
    # 使用 Confusion-Aware CBST
    scale_probs_list = [
        F.softmax(target_output['scale_1s_logits'], dim=1),
        F.softmax(target_output['scale_2s_logits'], dim=1),
        F.softmax(target_output['scale_4s_logits'], dim=1),
    ]
    selected_indices, selected_labels, cbst_diag = confusion_fix['ca_cbst'](
        fused_probs, scale_probs_list, quota_per_class
    )
else:
    # 使用原始 CBST
    selected_indices, selected_labels = cbst_select(...)
```

#### **插入点 6：损失计算时加入非对称损失**（约第 450-500 行）
```python
# 计算总损失
total_loss = source_loss + target_loss + ...

# 【新增】非对称混淆损失
if confusion_fix['asy_loss'] is not None:
    asy_loss, asy_diag = confusion_fix['asy_loss'](
        fused_logits=target_output['fused_logits'],
        pseudo_labels=selected_labels,
        scale_probs=torch.stack(scale_probs_list, dim=1),  # [N, 3, 3]
        features=target_output['features'],  # 如果有特征输出
    )
    total_loss = total_loss + 0.3 * asy_loss
```

## 🔧 故障排查

### 问题 1：模块未被调用
**症状**：结果与 baseline 完全一样

**检查**：
```python
# 在训练脚本中加入打印
print(f"Iteration {iteration}: asy_loss enabled = {confusion_fix['asy_loss'] is not None}")
```

### 问题 2：GPU 内存不足
**症状**：训练崩溃，日志显示 CUDA OOM

**解决**：
- 减小 batch size（在 `settings()` 中修改）
- 关闭某些模块（先测试单模块）

### 问题 3：数值不稳定
**症状**：loss 变成 NaN

**检查**：
- 校准强度是否过大（降低 `correction_strength`）
- margin 是否过大（降低 `margin_strength`）
