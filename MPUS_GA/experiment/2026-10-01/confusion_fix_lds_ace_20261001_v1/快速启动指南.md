### 快速查看某个方向的混淆矩阵
```python
import json
import numpy as np

# 读取一个结果文件
result_file = "results_confusion_fix_lds_ace_20261001_v1/baseline/A/seed_43_subject_01.json"
with open(result_file, 'r') as f:
    result = json.load(f)

# 混淆矩阵（trial 级）
cm = np.array(result['trial_evaluation']['confusion_matrix'])
print("混淆矩阵:")
print(cm)

# 归一化（按行）
cm_norm = cm / cm.sum(axis=1, keepdims=True)
print("\n归一化混淆矩阵:")
print(cm_norm)
```

## 常见问题

### Q1: 任务显示失败
查看具体日志：
```bash
tail -100 /home/gzw/projects/MPUS_GA/logs/confusion_fix_lds_ace_20261001_v1/<config>/<direction>.log
```

常见原因：
- 数据路径错误
- GPU 内存不足
- 代码有 bug

### Q2: 进度很慢
检查：
- 是否两个 GPU 都在工作
- 是否有其他进程占用 GPU
- 查看 `nvidia-smi` 确认 GPU 利用率

### Q3: 想优先跑某个配置
修改 `scripts/run_confusion_fix_suite.sh` 中的任务队列顺序，将想要的任务移到前面。

### Q4: 想加入新的配置
1. 在 `train_confusion_fix.py` 的 `parse_config` 中添加新配置
2. 在任务队列中添加对应的任务名
3. 重新启动调度器
